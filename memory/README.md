# Memory

Session logs land in `sessions/`, written by the `/done` skill at the end of a working chat (`YYYY-MM-DD-topic.md`). They're what lets a fresh chat pick up where the last one left off — open a new chat anytime; don't live in one endless thread.

Durable facts don't pile up here — `/done` routes them to where they auto-load:
- people facts → `people.md`
- facts about the pod's grants, processes, or how water PM work gets done → `water-pm-reference.md`
- facts about GiveWell research itself → `research-reference.md`
- project state → `projects/active.md` and the project's `notes.md`
- working conventions and preferences → `CLAUDE.md`
