# Meetings

Processed meeting notes land here, written by the `/process-meeting` skill.

Naming: `YYYY-MM-DD-topic.md` (e.g., `YYYY-MM-DD-water-pod.md`, `YYYY-MM-DD-1-1.md`, `YYYY-MM-DD-<organization>.md` for a grantee or partner call).

To process a meeting: get the transcript (a Granola/Zoom/Otter export, or paste it), then run `/process-meeting` and point it at the file. It writes structured notes here and proposes action items (and Asana tasks if you confirm). When a meeting moves one of your projects, the skill also proposes the matching `projects/active.md` update; for an external call, it can propose the notes link for the pod's stakeholder tracker.

Process the routine ones too, not just the big ones. A 1:1 where a date slipped or an owner changed is exactly the kind of context that gets lost if it isn't written down the same day.
